    실시간 모의매매 전략 설정

    상태 확인 중

    전략과 자금 한도를 변경합니다. 이동평균 기간은 교차 전략에, 매수 주기는 분할매수에, 목표 비중·편차는 리밸런싱에 적용됩니다. 거래를 정지한 뒤 저장할 수 있으며 저장 후 자동으로 시작되지 않습니다.

    현재 설정을 불러오고 있습니다.

    디시젼 게이트

    상태 확인 중

    이동평균·분할매수·리밸런싱 공통으로, 매수·매도 신호 후 OpenRouter Decisions(typesafe/jev-1.14)로 최종 진행 여부를 판정합니다. 백테스트에는 적용되지 않습니다.

    현재 설정을 불러오고 있습니다.

    설정 적용 기준

    • 저장한 설정은 서버를 재시작해도 유지됩니다. 백테스트 입력값은 별도로 관리합니다.
    • 원화·BTC 잔고, 기존 체결, 일일 손실 기준 자산은 그대로 유지합니다.
    • 보유 한도를 낮춰도 기존 BTC를 강제로 매도하지 않습니다. 이후 매수에 새 한도를 적용합니다.
    • 이미 판단한 캔들은 설정을 바꿔도 다시 거래하지 않습니다. 새 캔들에서 변경된 전략을 사용합니다.
    • 신규 매수 중지 상태는 설정 저장으로 해제되지 않습니다. 실시간 화면에서 별도로 재개하세요.
